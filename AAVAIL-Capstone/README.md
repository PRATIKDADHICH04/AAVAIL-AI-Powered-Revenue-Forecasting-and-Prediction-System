# AAVAIL Revenue Prediction & Monitoring API

A starter capstone implementation for the IBM AI Enterprise Workflow / AAVAIL business case. It demonstrates ingestion, EDA-ready data, model comparison, a Flask prediction API, logging, unit tests, and Docker deployment.

> **Important:** `data/revenue.csv` generated by `scripts/make_demo_data.py` is synthetic demo data. Replace it with the actual course-provided AAVAIL data and validate the column mapping and results before submitting. Do not claim demo metrics as real business results.

## 1. Setup

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Prepare data

Expected normalized columns: `date,country,revenue`.

For a quick smoke test only:
```bash
python -m scripts.make_demo_data
```

For the actual course dataset, use:
```bash
python -m scripts.ingest_data path/to/course_data.csv --output data/revenue.csv
```
Review `scripts/ingest_data.py` if the course file uses different column names or revenue definitions.

## 3. Train and compare models

```bash
python -m scripts.train
```

The training script compares a mean baseline, Random Forest, and HistGradientBoosting using a chronological holdout split and MAE/RMSE/R². It saves the best non-baseline model to `models/`. Review the split strategy and add a stronger time-series baseline / backtesting before final submission.

## 4. Run API

```bash
python -m app.app
```

Country-specific request:
```bash
curl -X POST http://localhost:5000/predict -H "Content-Type: application/json" -d '{"target_date":"2024-01-15","country":"USA"}'
```

All known countries combined:
```bash
curl -X POST http://localhost:5000/predict -H "Content-Type: application/json" -d '{"target_date":"2024-01-15"}'
```

Health:
```bash
curl http://localhost:5000/health
```

## 5. Tests

```bash
pytest -q
# or
sh run_tests.sh
```

Tests use fake models and temporary test log files; they do not overwrite production model artifacts or application logs.

## 6. Docker

Train the model first so `models/best_model.joblib` and `models/metadata.json` exist, then:
```bash
docker compose up --build
```
